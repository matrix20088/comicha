# كوميكها (Comicha)

نسخة مبسطة جدًا: المستخدم يكتب موقف واحد، والتطبيق يحوله في الخلفية إلى Prompt احترافي ثم يولد صفحة كوميك كاملة كصورة واحدة.

## تجربة المستخدم
1. اكتب الموقف.
2. اضغط «حوّل الموقف لكوميك».
3. استلم صورة كوميك كاملة باللهجة المصرية العامية.
4. نزّل PNG أو شاركها.

لا توجد اختيارات للستايل أو اللهجة أو عدد الكادرات. التطبيق يقرر ذلك تلقائيًا.

## الذكاء الاصطناعي
الخادم يستخدم OpenAI Images API بنموذج افتراضي:

`gpt-image-2.5-flare`

يمكن تغييره عن طريق:

`OPENAI_IMAGE_MODEL`

ويجب إضافة:

`OPENAI_API_KEY`

في Vercel Environment Variables للتوليد الحقيقي.

## الملفات
- `index.html` الواجهة
- `styles.css` التصميم
- `app.js` منطق المتصفح
- `api/generate.js` بناء البرومبت واستدعاء مولد الصور
- `vercel.json` إعدادات النشر
