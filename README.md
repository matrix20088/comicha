# كوميكها (Comicha)

تطبيق ويب عربي يحوّل وصف أي موقف إلى كوميك كامل: سيناريو، كادرات، شخصيات، حوار مصري عامي، وصور مولّدة بالذكاء الاصطناعي.

## المزايا الحالية
- وضع **اشرح موقف**: المستخدم يكتب موقف فقط والـAI يؤلف الحوار والكادرات.
- وضع **نص جاهز**: يحافظ على كلام المستخدم ويقسمه لكوميك.
- 2 / 4 / 6 كادرات.
- لهجة مصرية عامية افتراضيًا.
- 6 ستايلات بصرية.
- توليد كل كادر بصورة مستقلة مع إمكانية إعادة رسمه.
- تعديل الحوار والكابشن مباشرة من النتيجة.
- تنزيل الكوميك النهائي PNG من المتصفح.
- مشاركة الصورة عبر Web Share API على الأجهزة الداعمة.
- Demo mode تلقائي لو لم تتم إضافة مفتاح Gemini.

## تشغيل الذكاء الاصطناعي على Vercel
أضف Environment Variable باسم:

`GEMINI_API_KEY`

اختياريًا يمكن تغيير النماذج:

`GEMINI_TEXT_MODEL=gemini-3.8-flash`

`GEMINI_IMAGE_MODEL=gemini-3.1-flash-image`

المفتاح يبقى على السيرفر ولا يتم إرساله للمتصفح.

## النشر
المشروع بدون build step: ملفات Static + Vercel Node Functions داخل `/api`.
اربط الريبو بـ Vercel وسيتم النشر تلقائيًا مع كل Push على `main`.
